# 🏡 WanderStay – Full Stack Listing Platform

WanderStay is a full-stack web application built with Node.js, Express, MongoDB, and EJS.  
It allows users to create, edit, and manage property listings with authentication and review functionality.

---

## 🚀 Features

- 🔐 User Authentication (Register / Login / Logout)
- 🧾 Session Management with Express-Session
- 🗄 MongoDB Atlas Database Integration
- 🏠 Full CRUD Operations for Listings
- ⭐ Add & Delete Reviews
- 🛡 Server-side Validation using Joi
- ⚡ Flash Messages for Success & Error Alerts
- 🔒 Secure Configuration using Helmet & Environment Variables
- 🧠 Error Handling Middleware
- 🌍 Production-ready setup with MongoDB Session Store

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Passport.js
- EJS & EJS-Mate
- Joi
- Helmet
- Connect-Mongo
- Method-Override

---

## 📦 Installation

1. Clone the repository
2. Install dependencies:
   npm install
3. Create a `.env` file and add:
   ATLASDB_URL=your_mongodb_url
   SECRET=your_session_secret
4. Run the server:
   nodemon app.js
